Que es un plugin

Un plugin de KRYPTOS es un solo archivo .html autocontenido — CSS y JS embebidos ahi mismo, sin dependencias externas — mas un plugin.json que lo describe. Nada mas.

Se carga dentro de un <iframe sandbox="allow-scripts">: corre tu codigo, pero no tiene acceso a los comandos de Tauri, al sistema de archivos, ni a nada del resto de la app. Es el mismo criterio de "nada se ejecuta a ciegas" que ya usa el resto de KRYPTOS, aplicado a lo que vos mismo instales.

plugin.json

namenombre visible (requerido)
versionversion, cualquier texto (requerido)
entryarchivo .html a cargar (requerido)
descriptionuna linea, opcional
authoropcional
iconun emoji, opcional
Ejemplo minimo
{
  "name": "Mi plugin",
  "version": "1.0.0",
  "entry": "index.html"
}

Como instalar el tuyo

Ponete plugin.json y tu index.html en una carpeta (o comprimilos en un .zip) y usa el boton "Instalar" arriba de la lista de Plugins. Podes desactivarlo o desinstalarlo cuando quieras — nunca queda corriendo algo que no elegiste vos.
